Getting an engine running

xokolat does not generate anything itself. It asks something that does — and that something has to be running before there is anything to ask. These are the guides for the ones it knows how to talk to.

Every one of them has the same two routes, and neither is more correct than the other:

  • Open the app and switch its server on. Draw Things and ComfyUI both have one. Nothing to install, nothing to configure — but the app has to stay open for xokolat to reach it.
  • Run it headless, in the background. A per-user launch agent that starts at login and restarts if it dies. No window, nothing to remember, and xokolat finds it already answering every time. This is the route with the traps in it, which is why these pages exist.

Once one is running, open 🔌 inference in xokolat and press ↻ on its card. If the card says reachable and lists checkpoints, you are done.

Draw Things → images The gRPC server. Every picture xokolat makes today comes from here. macOS only. ComfyUI → images, and everything else Graph-based, runs anywhere. Music, voice, video and 3D all come from here. Ollama → words A local language model for xoko, the app's brain. The smallest of the three. Engines in the background Run them as services, and keep them updated — the half that fails silently.

Why headless is worth the ten minutes

The app-window route is genuinely fine, and if it suits you there is nothing wrong with it. What you give up is smaller than it sounds and more annoying than it sounds: the engine is only there when you remember to put it there. A machine that has been asleep, a Mac that rebooted for an update, a window you closed to free memory — each one turns xokolat into an app with a red card on it until you notice why.

A launch agent removes the noticing. It also means the engine is not competing with a UI for the GPU, and that logs land in a file you can read rather than scrolling past in a terminal.

These pages ship with xokolat and are also published at xoko.lat, so you can read them before installing anything.
